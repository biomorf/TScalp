## Запрещено

- Менять UI без явной санкции.
- Генерировать код, который «примерно должен работать» — если
  ассистент не уверен в API/сигнатуре, он говорит об этом.
- Оставлять `TODO` без согласования — либо решаем сейчас, либо
  записываем в `docs/ROADMAP.md` / `docs/ISSUES.md`.
- Коммитить без проверки. Desktop: полный локальный гейт обязателен.
  Mobile: WIP-коммит с маркером, компиляция проверяется в CI.
- Открывать PR без зелёного CI `gate` на последнем коммите
  feature-ветки.
- Использовать `android.util.Log` вместо `AppLogger`.
- Использовать `DataStore` напрямую — только через
  `SettingsRepository`.
- Ходить из ViewModel к брокеру напрямую — только через
  `InvestRepository`.
- Использовать git-команды с дефолтами (`git push`,
  `git add .`, `git pull`, `git checkout` без имени и т.п.) —
  см. 4g.
- Принимать решение или планировать задачу без проверки триады
  Clean + MVVM + KMP-ready (2e). Молчаливое отклонение запрещено.
