# AGENTS.md — директивы для ИИ-ассистента

Документ описывает правила работы ИИ-ассистента над проектом TScalp
(Android-приложение для торговли через T-Invest, BCS, Finam).
Читается в начале каждой сессии. Применяется без исключений,
кроме случаев, когда пользователь явно отменяет правило.

---










<!-- SECTION_BEGIN: docs -->
## Обязательные документы

Обязательные файлы, порядок чтения и формат отчёта —
`AGENTS/AGENTS-docs.md` (`docs-gate`). Набор уроков —
`AGENTS/AGENTS-LESSONS-docs.md`. Без отчёта о прочтении работа
не начинается.

**Причина:** правила разнесены по файлам (`AGENTS-style-*`,
`AGENTS-code.md`, `AGENTS-project-docs.md`, …). Перечень в одном месте —
единственная точка, где видно, что прочитано не всё (инцидент
2026-11-22: гейт покрывал 5 файлов из 17).
