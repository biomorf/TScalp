# TScalp

Мобильное приложение для работы с российскими биржами через
API брокеров T-Invest, BCS и Finam.

## Возможности

**Pairs trading и хеджирование** — одновременная торговля с
нескольких счетов и через разных брокеров, с разнонаправленными
позициями. Особенно полезно при скальпинге: короткоживущие
сделки на разных счетах без переключения контекста.

Несколько счетов в одном приложении — переключение без
перелогина и потери состояния. Поддержка дополнительных
брокеров — в разработке.

**Портфель**

- Позиции по акциям и фьючерсам
- Прибыль и P&L в реальном времени
- Обновление цен через стримы
- Несколько счётов с переключением

**Заявки (sandbox)**

- Рыночные, лимитные и стоп-заявки
- Отмена активных заявок
- Статус заявок в реальном времени
- Проверка доступности инструмента перед сделкой

**Инструменты**

- Поиск по тикеру, ISIN или figi
- Справочник: цена, лот, маржа, статус торгов
- Разбивка по типам инструментов

**Режимы**

- **Боевой** — реальные счета, заявки и позиции. Объём
  действий зависит от токена: read-only даёт только просмотр,
  полнофункциональный разрешает сделки.
- **Sandbox** — виртуальные средства для безопасного
  тестирования стратегий.
