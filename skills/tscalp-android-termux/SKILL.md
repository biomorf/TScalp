# TScalp: расширенный доступ (Termux + SSH)

Этот файл — только про режим доступа. Правила кода, git, документации и среды — в `AGENTS.md`, здесь не дублируются.

## 1. Первое действие сессии

Прочитай `AGENTS.md` в корне текущей директории и строго соблюдай его правила. Он важнее этого файла. Индекс — `AGENTS/AGENTS.md`, уроки — `AGENTS-LESSONS.md`.

## 2. Режим работы: строго только чтение

Ассистент **никогда не изменяет состояние репозитория**. Без исключений, без обходных путей, без «по умолчанию».

**Разрешено:** читать файлы и показывать их содержимое.

**Запрещено всегда:**

- создавать, править, перемещать и удалять файлы — любым способом (`>` и `>>`, `sed -i`, `tee`, `mv`, `rm`, `touch`, редакторы, `docs_add` / `docs_cut` с `--apply`, `docs_normalize --apply`, `docs_rebuild_index --apply`);
- любые операции, меняющие git: `git add`, `git commit`, `git push`, `git checkout`, `git switch`, `git stash`, `git merge`, `git revert`, `git tag`, `git branch` (кроме чтения);
- деструктивные команды: `git reset --hard`, `git clean -f`, `git push --force`, `git branch -D`, `git push --delete`, `git remote remove`, `rm -rf`, `find -delete`, `chmod -R`, `truncate`;
- запуск сборки и тестов, создающих артефакты: `./gradlew …` (пишет `build/`, кэши), `adb install`, любые команды, меняющие рабочее дерево.

**Изменения выполняются только так:** ассистент выдаёт готовый скрипт или блок команд, пользователь применяет его локально сам. Готовый блок — по формату `4i` шаблон 1, правки `.md` — по `4c`.

## 3. Диагностика по репозиторию

Любая команда, обращённая к репозиторию (`git status`, `git log`, `git diff`, `docs_lint.py`, `grep`, `ls`, `cat`), выполняется **только после явного утвердительного ответа пользователя** на конкретный запрос.

- Согласием считается только явное «да» / «запускай» / «проверь».
- Молчание, отсутствие возражения, ответ на другой вопрос, «раньше разрешал» — **не согласие**.
- Разрешение даётся на один запрос и на перечисленные в нём команды. Следующий запуск — следующий запрос.

## 4. Если правило мешает

Ассистент не толкует это правило и не ищет обходных путей. Если нужна запись или диагностика — он **просит разрешение** и ждёт ответа. Менять рамку может только пользователь, явно.

## 5. Границы рабочей области

- Работать только внутри корня проекта: `git rev-parse --show-toplevel`.
- Никаких `../`, никакого сканирования `$HOME`, никаких обращений за пределы проекта.
- Пути — относительные от корня: `./app/src/...`, `./gradlew`.

## 6. Среда

Termux: нет `/usr/bin`, используй `$PREFIX/bin`, `$PREFIX/etc`, `$PREFIX/tmp`; `sudo` и `systemctl` недоступны. Сборку запускает **пользователь**, с системным AAPT2:

```bash
./gradlew assembleDebug -Pandroid.aapt2FromMavenOverride="$PREFIX/bin/aapt2"
```

Ограничения по памяти и порядок работы — `AGENTS.md` → `code-workflows`.
